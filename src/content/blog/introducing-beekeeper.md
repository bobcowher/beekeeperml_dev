Beekeeper is a lightweight web app designed to let you run AI training jobs on a remote server from the comfort of your own machine. In this first video, I walk through what Beekeeper is, why I built it, and how to get it set up on your home lab.

To get started, clone the repo and run the setup script — you'll have a web UI running on port 5000 in minutes.
